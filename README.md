---

## Pré-requisitos

Antes de começar, certifique-se de ter as seguintes ferramentas instaladas na sua máquina:
- Git
- Node.js (Versão 18 ou superior recomendada)

---

## Como Rodar a Aplicação na sua Máquina

Siga o passo a passo abaixo para clonar e executar o projeto localmente:

### Passo 1: Clonar o Repositório
Abra o seu terminal e execute o comando abaixo para clonar o projeto:

`git clone https://github.com/rafamarques09/avaliacaoTecnico.git`

### Passo 2: Entrar na Pasta Backend
Acesse o diretório do backend onde estão as dependências e o servidor:

`cd sistemaMercado/backend`

### Passo 3: Criar o Arquivo .env
Crie um arquivo chamado `.env` na raiz da pasta `backend` com as configurações do seu ambiente local. Exemplo:

PORT=3000

DB_HOST=localhost

DB_PORT=3306

DB_USER=root

DB_PASSWORD=sua_senha

DB_NAME=mercado

### Passo 4: Instalar as Dependências
Instale todos os pacotes necessários:

`npm install`

### Passo 5: Iniciar o Servidor
Execute o comando para rodar a aplicação:

`node server.js`

Pronto! O servidor estará rodando e pronto para receber requisições.
